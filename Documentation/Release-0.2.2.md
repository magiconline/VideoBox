# VideoBox 0.2.2（构建 4）

2026-09-05 · 第一轮导出正确性与播放器交互修复

## 本版完成

- 预览使用剪辑后的真实组合时间线。删除、复制、重排、变速后，播放位置、总时长、字幕源时间与当前片段统一映射；不会快进到已删除部分。
- 拖动进度时暂停，松开后按拖动前状态决定是否继续播放；拖到末尾保持停止。快速连续操作采用最新定位请求，换源会取消旧任务。
- 逐帧读取真实显示帧时间，不假设固定帧率。处理 MP4/QuickTime edit list、B 帧前置时间和用户剪辑之间的映射；格式无法提供精确帧游标时显示原因。
- 原生全屏复用播放器视图；监听静音和音量独立，不修改片段音量或导出设置。
- LUT 比较线维持屏幕左右方向，仅其手柄区域响应比较拖动；旋转、镜像不交换原片与处理画面标签。
- 短片段最小宽度计入可滚动区域，播放头、刻度和拖动定位共用同一几何布局。
- 快速导出不再暗中转为重新编码。移除音频正确生效；两种导出按钮、入队和执行使用同一校验与阻止原因。
- 修复 AV1 编码参数、480p 奇数尺寸、硬件位深/采样静默回退风险；压缩完成后核对实际编码、位深与采样。
- 队列显示真实进度，取消会终止实际进程；写入临时文件，成功后才替换目标。禁止覆盖输入视频、轨道或 LUT，包括符号链接/硬链接别名。

## 播放器操作

先点击画面或时间线聚焦。文字编辑、文件选择及快捷键帮助弹窗中，不接管播放器按键。

| 操作 | 鼠标 / 键盘 |
| --- | --- |
| 播放、暂停 | 单击画面 / 空格 |
| 前后 5 秒 | ← / → |
| 前后 1 秒 | Shift + ← / → |
| 上一帧、下一帧 | 英文逗号 `,` / 句号 `.` |
| 全屏 | 双击画面 / F |
| 退出全屏 | Esc / F |
| 监听静音 | M |
| 监听音量增减 5% | ↑ / ↓ |
| 查看操作说明 | 播放器右下角键盘按钮 |

片段工具条的音量影响导出；播放器控制条的监听音量不影响导出。

## 验证

- 最终 `swift test`：84 项通过，0 失败、0 跳过（2026-09-05 15:57:44，Asia/Shanghai）。
- 真实文件测试：快速移除音频后视频包 SHA-256 保持一致；480p 输出 854×480；AV1 编码有效；取消导出保留已有目标并清理部分输出；源文件覆盖被拒绝。
- 真实帧测试：30fps 视频 0.500→0.533333；带 B 帧的变帧率视频 0.500→0.700、0.700→0.500。
- 窗口实测：方向键、逐帧、空格、F/Esc、单击/双击、LUT 分隔线拖动、监听音量与文字输入焦点保护；12 秒测试片段删去尾部后总时长同步缩短，快进不能越界。
- 指定 DJI LUT 从文件选择器成功加载，快速导出显示禁用原因。界面提交压缩导出并自动入队完成，检查输出为 HEVC、8-bit、4:2:0、BT.709、Limited，含 AAC 音轨。另有 10-bit HEVC LUT 编码实验通过。
- 测试使用合成画面，验证加载、预览和导出链路，不代表该画面是真实 D-Log M 素材，也不是色准校准结果。
- 窗口测试使用同一 Release 构建的独立标识副本，避免机器上两份同名应用影响自动化定位；最终应用仍使用原标识 `com.videobox.mac`。

## 明确保留的能力边界

- 尚未实现独立 HDR/色域转换、动态 HDR 元数据可靠保留、相机 Log 自动识别。界面使用“输入 Log 声明”和“LUT 输出标签”，不把元数据标记当作真实转换。
- 本版明确阻止外部字幕烧录和非零烧录偏移。改变源时间轴后移除旧章节，并在界面提示；章节重映射未实现。
- 快速导出裁切仍受关键帧限制，需要精确剪切时使用压缩导出。
- 已覆盖本机样片与随包编码器，不代表所有相机格式、显示器、HDR 场景均已验收。
