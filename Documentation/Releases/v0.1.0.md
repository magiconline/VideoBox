# VideoBox v0.1.0 — First public preview / 首个公开预览版

## 中文

这是 VideoBox 的首个公开预览版，面向 macOS 13 及以上系统，同时支持 Apple Silicon 与 Intel Mac。

主要能力：

- 视频信息、轨道、章节与元数据检查
- AVFoundation 原生播放预览
- 时间线分割、复制、删除、排序与片段级变换
- 快速码流复制与可配置压缩导出
- FFmpeg 命令预览与后台导出队列

安装前请注意：

- 需要另行安装 FFmpeg 与 ffprobe（推荐 `brew install ffmpeg`）。
- 当前 DMG 为临时签名且尚未通过 Apple 公证；如首次启动被阻止，请按住 Control 点击应用并选择“打开”。
- 当前界面语言为简体中文。

下载后可使用随附的 `.sha256` 文件校验 DMG 完整性。

## English

This is the first public preview of VideoBox for macOS 13 and later. The universal build supports both Apple Silicon and Intel Macs.

Highlights:

- Video, track, chapter, and metadata inspection
- Native AVFoundation playback
- Timeline splitting, duplication, deletion, reordering, and per-clip transforms
- Fast stream copy and configurable compressed export
- FFmpeg command preview and a background export queue

Before installing:

- FFmpeg and ffprobe must be installed separately (`brew install ffmpeg` is recommended).
- The current DMG is ad-hoc signed and not Apple-notarized. If macOS blocks the first launch, Control-click the app and choose **Open**.
- The current interface is in Simplified Chinese.

Use the accompanying `.sha256` file to verify the downloaded DMG.
