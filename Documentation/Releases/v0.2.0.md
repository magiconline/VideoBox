# VideoBox v0.2.0 — FFmpeg included / 内置 FFmpeg

## 中文

VideoBox v0.2.0 是首个自带完整媒体运行时的公开预览版，面向 Apple Silicon Mac。安装 ARM64 DMG 后即可直接使用，不再需要 Homebrew，也无需另行安装 FFmpeg。

本版包括：

- 内置 ARM64 原生 `ffmpeg` 与 `ffprobe`，应用会优先使用包内版本。
- 保留 H.264（`libx264`）和 H.265/HEVC（`libx265`）软件编码。
- 提供 SVT-AV1、Opus、ProRes，以及 H.264/HEVC VideoToolbox 硬件编码。
- 提供基于 libass 的字幕烧录能力。
- 随 DMG 发布运行时的完整对应源码、固定版本、SHA-256 校验值和构建脚本。
- VideoBox 应用源码继续采用 MIT License；包内 FFmpeg 运行时按 GPL-2.0-or-later 及各组件许可证分发。

安装：打开 DMG，将 **VideoBox** 拖入 **Applications（应用程序）**。本预览版为临时签名且尚未通过 Apple 公证；如果 macOS 阻止首次启动，请按住 Control 点击应用并选择“打开”。

下载后可使用同名 `.sha256` 文件检查 DMG 与对应源码归档的完整性。

## English

VideoBox v0.2.0 is the first public preview with a complete media runtime included, targeting Apple Silicon Macs. Install the ARM64 DMG and start using it without Homebrew or a separate FFmpeg installation.

This release includes:

- Native ARM64 `ffmpeg` and `ffprobe`, preferred automatically by the app.
- Software H.264 (`libx264`) and H.265/HEVC (`libx265`) encoding.
- SVT-AV1, Opus, ProRes, and H.264/HEVC VideoToolbox hardware encoding.
- Subtitle burn-in powered by libass.
- Complete corresponding runtime source, pinned versions, SHA-256 checksums, and build scripts published beside the DMG.
- MIT licensing for the VideoBox application source; the bundled FFmpeg runtime is distributed under GPL-2.0-or-later and the component licenses listed in the notices.

To install, open the DMG and drag **VideoBox** to **Applications**. This preview is ad-hoc signed and not yet Apple-notarized. If macOS blocks the first launch, Control-click the app and choose **Open**.

Use the accompanying `.sha256` files to verify both the DMG and corresponding-source archive.
